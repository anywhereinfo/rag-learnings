# RAG Learnings

This repository serves as a collection of demonstrations and practical examples from my journey learning about Retrieval-Augmented Generation (RAG).

## Structure

The repository is organized into numbered folders, each focusing on a specific concept or component of the RAG pipeline.

### 1. Embeddings (`/embeddings`)
- **Focus**: Understanding vector embeddings, semantic similarity, and visualization.
- **Key Concepts**:
    - Generating text embeddings using Vertex AI (`text-embedding-004`).
    - Computing Cosine Similarity.
    - Dimensionality reduction using PCA.
    - Visualizing embeddings in 2D space.
